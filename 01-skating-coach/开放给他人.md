# 开放给他人使用（体验版路线）

> 目标：先给朋友 / 同学用，**不备案、不审核、不公开发布**。
> 这条路 30 分钟能跑完；正式上架另见文末。

## 一、先决定 AI 教练怎么处理（涉及你的钱）

AI 教练调用的是**你自己的 DeepSeek Key**，别人用就是花你的钱。
现在的代码默认：**AI 教练只给开发者本人用**——

- `login` 云函数会告诉客户端"你是不是本人" → **不是本人，首页就不显示 AI 教练入口**
- `deepseek` 云函数里还有一层兜底：**调用者 openid 不是本人就直接拒绝，而且根本不调用 DeepSeek**（不产生费用）
- **没配置 `OWNER_OPENID` 时，所有人都用不了**（包括你自己）——故意做成"失败即关闭"

### 配置步骤（一次就够）

1. 先拿到**你自己的 openid**：小程序 →「设置 → 数据概览/同步诊断」里会显示；或在云开发控制台 → 云函数 → `login` → 日志里能看到
2. 云开发控制台 → **云函数 → login → 配置 → 环境变量**，添加：
   - 键 `OWNER_OPENID`，值 = 你的 openid
3. 云开发控制台 → **云函数 → deepseek → 配置 → 环境变量**，添加同样的 `OWNER_OPENID`
4. 两个云函数都**重新部署**一次
5. 自己打开小程序确认 AI 教练入口还在（别人打开应该看不到）

> 想让朋友也能用 AI：把他们的 openid 加进去（现在只支持一个值；要多人就用逗号分隔并改一行代码，说一声我改）。

## 二、两个数据库集合的权限（最要命的一条）

云开发控制台 → 数据库 → 每个集合 → **权限设置**：

| 集合 | 必须是 |
|---|---|
| `planner_data` | **仅创建者可读写** |
| `planner_history` | **仅创建者可读写** |

设错了（比如"所有用户可读"）别人就可能读到你的训练记录。
代码侧已经做了双保险：所有读写都走 `doc(自己的 openid)`，历史快照查询也显式带 `_openid` 条件——但**控制台配置仍然是第一道门**，务必核对。

## 三、把体验版发给朋友

1. 开发者工具 → 右上角「上传」→ 填版本号和备注 → 上传成功
2. 微信公众平台 → **管理 → 成员管理 → 体验成员 → 添加成员**，输入对方微信号
   - 一个小程序最多加 **60 个体验成员**（每个微信号最多是 50 个小程序的体验成员）
3. 开发者工具 → 版本管理 / 公众平台 → 把**体验版二维码**发给他们，扫码即用
4. 之后每次更新：重新上传 → 体验版二维码自动指向最新版，朋友重新打开就更新了

**体验版不需要备案、不需要审核**，这是它最大的好处。

## 四、朋友第一次打开会看到什么

- 空日历 + 「👋 第一次用，三步就上手」引导卡
- 动作库预置 30 个动作（默认 24 + 热身 3 + 专题练习 3）
- **看不到 AI 教练入口**（因为不是本人）
- **看不到姿态自查入口**（`utils/const.js` 里 `POSE_ENABLED = false`，真机识别还没跑通，对外先关；要放出来改成 `true` 并在 `app.json` 的 `pages` 里恢复 `pages/pose/pose`）

每个用户的数据完全独立（按 openid 一份文档），互相看不见。

## 四·五、配 OWNER_OPENID 时踩过的坑（照这个表排）

| AI 教练的回答 | 说明 | 怎么办 |
|---|---|---|
| 正常回答 | ✅ 配置成功 | — |
| `暂未开放：没读到 OWNER_OPENID（函数看到的相关变量名：…）` | 环境变量没被函数读到 | 看括号里列出的变量名：**一个都没有** = 没配到/deepseek 上；**有相似但不完全一样的名字** = 键名写错了（大小写、空格）。最省事的做法：把 openid 填进 `deepseek/index.js` 顶部的 `OWNER_OPENID_FALLBACK` 常量，重新部署即可（`login` 里也有同一个常量，建议一起填） |
| `暂未开放（鉴权失败：xxx）` | 云函数**代码抛异常**了 | 看括号里的原因。踩过：`deepseek` 原来只用 `https` 调 API，**没 require 过 `wx-server-sdk`**，加鉴权时直接 `cloud is not defined`（已修：补上 require + `cloud.init`）；改完必须**重新部署 deepseek** |
| `目前仅开发者本人可用` | openid 配错了 | 多半粘成了**开发者工具**的测试 openid，要用**手机上**看到的那个 |

> 冒烟测试里加了一组「云函数」检查：用了 `cloud.xxx` 却没 `require('wx-server-sdk')`、require 了却没 `cloud.init()`、`package.json` 缺依赖、语法错误 —— 都会直接报出来。

## 五、要盯的两件事

1. **云开发配额**：云开发控制台 → 用量。所有用户共用你的环境，容量不是瓶颈（每人约 200KB，60 人 ≈ 12MB），
   但**数据库读写次数 / 云函数调用次数**有每日上限，人多了会撞。先看配额再决定放多少人。
2. **隐私保护指引**：公众平台 → 设置 → 服务内容声明 → 用户隐私保护指引，声明收集 openid 与训练记录。
   小程序里「设置」页也提示了数据导出方式，方便他们自己备份。

## 六、以后想正式上架（面向所有人）

1. **必须先完成小程序备案**（2023-09-01 起，未备案不能上架；个人主体也能备案，需身份证 + 人脸核验，要等几个工作日）
2. 服务类目：个人主体可选类目有限，工具/运动记录类通常可以，以平台给的清单为准
3. 隐私保护指引 +（若开放 AI）大模型生成内容的相应资质与内容安全检测
4. 提交审核 → 发布

**建议**：先用体验版跑一两个月，确认功能和数据都稳，再启动备案。
