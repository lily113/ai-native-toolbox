# 真实数据 fixture（不入库）

这个目录用来放**你自己的真实导出**，让「升级演练」直接跑在你的真实数据上，
而不是我编的假数据。真机上的数据形态只有这份文件最清楚。

## 怎么放

1. 小程序 →「设置 → 数据备份 → 导出为文件」或「复制 JSON」；
2. 存成 `tools/mp_tests/fixtures/real-export.json`（就是导出的那段 JSON，原样存）；
3. 跑：`node tools/mp_tests/realdata.test.js`

## 它会做什么

把这份导出当成"你手机上装着旧版本时的全部数据"，完整跑一遍新版本的启动迁移，
然后逐项断言：

- 记录条数、每条 id、日期、类型 / 方式、节数 / 时长不变
- **原来写下的每一行文字都还在**（含 `notes` / `lessonSummary` 这类旧字段）
- 没有任何记录指向已不存在的动作
- 考级个性化内容、里程碑、基线 / 目标都在
- 升级自检通过（`upgradeCheck().ok === true`）
- 迁移是幂等的（再跑一遍数据完全一致）

数字对不上就会红字报出来，并打印是哪条记录、哪一行字。

## 注意

- **这个文件含你的个人训练笔记，不要提交到仓库**：`repo-updates/sync.sh` 已经把它排除在外，
  只有 `README.md` 会同步，`*.json` 不会。本地留着就行。
- 每次发新版本前重新导出一份覆盖它，等于"用最新真实数据做一次升级演练"。
