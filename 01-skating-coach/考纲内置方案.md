# 考纲内置方案（版权与做法）

## 一、结论：只内置「结构」，不复制正文

《国家花样滑冰等级测试大纲（第2版）》的版权页写得很明确：

```
中国花样滑冰协会 审定
出版发行：人民体育出版社      书号：ISBN 978-7-5009-6516-9
2026年2月第2版  定价 100.00元  **版权所有·侵权必究**
```

它是**正式出版物**（不是"国家机关文件"那种不受著作权保护的对象），把正文放进小程序分发给用户
= 复制 + 信息网络传播，属于著作权人的专有权利。**免费 ≠ 不侵权**。
正式上架审核时，含未授权出版物内容也可能被驳回。

所以 App 里**只放三类东西**：

| 放什么 | 为什么可以 |
|---|---|
| **级别与分节的名称**（如「第二章 单人滑步法表演节目」「重点步法说明」） | 事实性信息 / 标题，不受著作权保护 |
| **考核要素的名称**（如「单足后外弧线」「左、右后交叉步」） | 同上，是名称而非表达 |
| **用户自己写的要点**（「我的要点 / 我的易错」） | 用户自己的表达 |

**不放**：简介正文、完成要求、评判说明、减分明细等一切成段文字；也不复制书里的图案图片。

官方原文的获取方式在 App 里写清楚：《国家花样滑冰等级测试大纲（第2版）》，中国花样滑冰协会审定，人民体育出版社。
（提示：原书很多页带**整套动作二维码**，可以让用户扫码看官方示范，比我们复制文字更干净。）

## 一·五、级别清单（依据第一章 总则，共 42 个级别）

原书第一章总则写明了四类项目的级别划分，骨架就按它建：

| 项目 | 级别 | 数量 |
|---|---|---|
| 自由滑 | 1–10 级 | 10 |
| 步法 | 基础级 + 1–10 级 | 11 |
| 冰上舞蹈 | 1–6 级 | 6 |
| **成人** | 自由滑 1–6 级 + 步法 1–6 级 | 12 |
| **双人滑** | 1–3 级 | 3 |

⚠️ **key 必须全 ASCII**（`free-1` / `steps-0` / `adult-f3` / `pair-2` …）。
踩过的坑：一开始用中文当 key（`steps-一级`），列表页跳详情页时把 `id=sy_steps-一级` 直接拼进
`navigateTo` 的 URL，中文参数被转坏 → 详情页找不到 → 报**「考级不存在」**。
现在 key 全 ASCII，跳转前还做了 `encodeURIComponent`，冒烟测试里也钉了"key 必须 ASCII 且唯一"。

## 二、现在这件事做到哪一步了

- ✅ **级别骨架齐了**：步法（基础级 + 一~十级）、自由滑（一~十级）、冰上舞蹈（一~六级），共 27 个级别
  每个级别只带"官方分节名称"（步法：步法简介 / 重点步法说明 / 测试标准明细；自由滑：测试内容 / 通过标准 / 未通过标准；冰舞：目的和任务 / 测试内容 / 测试标准明细）+ 一个可编辑的「我的要点」
- ✅ 每个级别都能设考级日期、看倒计时、记入纪念日（复用原有能力）
- ✅ 考级详情页底部加了出处声明
- ✅ **唯一带正文的是「步法 · 四级」**——那是用户自己从纸质书转录、原本仅供自己备考用的，暂时保留
- ✅ **步法的官方要素名已经抽好**：基础级 + 一~十级每级的「重点步法说明」下都有官方要素名（共 42 条），
  只放**名称**，要点/易错留空给用户自己填。来源是原书每级的「（1）重点步法包括：」和「重点步法说明」表
  （如一级：前外单足弧线 / 前内单足弧线 / 左、右前交叉步；十级：4个外勾步 / 4个内勾步 … / 内刃变外刃的大一字步）
  - ⚠️ 这些名称是 OCR 抽出来后人工校正的（例如基础级原书表里是"左右侧蹬冰滑行 / 左前交叉步 / 左右单足支撑滑行"，
    OCR 认成了"橙冰""口点"），**建议你打开对照原书抽查两三级**
  - 「本级步法明细」这一节我改成了**可自己加条目**（官方全文太多，不复制；你要补 29 步那种逐条明细就加在这里）
- ⏳ **还没做**：冰上舞蹈（每级的"重点步法："和规定舞名称）、自由滑/成人每级的"测试内容（规定动作）"要素名

## 三、OCR 工具（扫描版 PDF → 中文文本）

原书是 185 页扫描件（无文字层），`pdftotext` 抽不出来，本机也没有 tesseract。
用 macOS 自带 Vision 写了个小工具：

```bash
cd tools/pdfocr && clang -fobjc-arc -O2 -fmodules-cache-path=./.mcache \
  -o ocrpdf ocr.m -framework Foundation -framework PDFKit -framework Vision \
  -framework CoreGraphics -framework AppKit
./ocrpdf <扫描PDF> [起始页] [结束页] > out.txt     # 每页输出 "=== PAGE n ===" + 文本
```

- 识别语言 zh-Hans + en-US，准确模式，×2.2 渲染（中文识别质量够读结构）
- 185 页大约几分钟
- 产物：`滑冰官方资料/抽取文本/大纲第2版-OCR原文.txt`
- ⚠️ **OCR 全文属于原书内容，只在本机留档，绝不进小程序包、绝不进公开仓库**（`滑冰官方资料/` 不在同步范围内）

## 四、如果以后要"更详尽"的正确做法

1. 抽**要素名称**做骨架（允许）
2. 想要正文？**给中国花样滑冰协会/人民体育出版社发授权申请**（非商业、教育用途、标注出处、不提供全文下载、附官方购买链接）
3. 或者**让用户自己导入**：App 不分发原文，用户把自己书上的内容贴进「我的要点 / 自建条目」（个人使用）
4. 想要图案/示范：**引导用户扫原书二维码或看官方渠道**，不复制图片

## 五、待处理的存量风险
