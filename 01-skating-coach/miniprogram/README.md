# 花样滑冰训练助手（微信小程序版）

一个**自己每天在用的花滑训练记录工具**：记上冰时长、动作、教练要点、冰感，按周看目标，对着国家等级测试大纲备考。

当前规模：**15 个主包页面 + 2 个分包页面**、17 套回归自测（1310 项断言）、**11 条静态体检**；
小程序已**完成 ICP 备案**、类目与隐私指引已就绪，待提审发布。

> **名字说明**：后台注册名是「花样滑冰训练助手」。备选新名是「冰刃手记 / Edge Journal」，等认证后（能"被搜索"）再一起改 —— 改名要连带做备案变更，所以不急着分两次做。
> 代码里名字只有一处来源：`utils/const.js` 的 `BRAND`，`app.json` 的导航标题由测试钉住"必须跟 `BRAND.cn` 一致"。

> PWA 网页版仍可正常使用；两者数据可通过「导出/导入 JSON」互转迁移。

## 给谁用：能力分三层

### ① 所有人可用

- **记录**（`pages/record`）：上冰 / 陆地；自己练 / 上课；**上课按节数**（1 节 = 30 分钟）自动算时长；训练时间段（滚轮 + 手动输入，结束时间 ⇄ 时长双向联动）；训练笔记（勾选动作/组合自动写入、手写文字不被覆盖、条目可 ↑↓ 排序）；动作搜索 + 最近用过 + ⚡ 复制上次；**冰感评分 0–5（只对冰上）**
- **首页**（`pages/index`）：月历（周一开头、可翻月、左右滑动切月）+ 当日记录 + **概览卡**（本月上冰天数 / 上冰时长 / 当月冰课数）+ 周目标进度 + 连续达标周 + 久未练习的动作提醒 + 考级倒计时
- **回顾**（`pages/review`）：月度统计（次数 / 总时长 / 上冰与陆地分开 / 上冰课与自练）+ 训练结构（分类占比）+ 教练·老师分布 + **冰感分析**（平均分、分布、好冰感距上次上冰几天）+ 近 12 个月上冰次数趋势 + 累计上冰 / 上冰课 / 节数
- **动作库**（`pages/moves`、`pages/move`）：动作级要点 + 练习组合（要点、新增日期、拖动排序）+ 分类可编辑（改名 / 新建 / 排序 / 删除，删除时先选移到哪、不静默丢）+ 多选批量整理 + 练习进度（已掌握 / 在练两种状态，已掌握的不再进"荒了"提醒）
- **考级备考**（分包 `packageExam`）：自由滑 / 步法按级别；内置考纲只读（含官方易犯错误）+ 步法图 + **我的要点 / 我的易犯错误 / 我的备注** + 自建分节与条目 + 批量粘贴 + 考级日期倒计时 + 一键记入纪念日
- **纪念日 / 里程碑**（`pages/milestone`）：上冰纪念、考级、比赛、第一次、康复、自定义
- **冰鞋 / 装备**（`pages/gear`）：填启用—退役日期，**自动从已上冰记录算出"滑了多少小时"**、平均每周、距上次磨刀多少天；换新鞋会把旧鞋记到当天退役
- **搜索**（`pages/search`）：按动作名 / 组合名 / 笔记文字搜历史记录，带摘要高亮
- **数据管理**（`pages/settings`）：周目标（可选，不设也能用）、次数基线、云同步（自动同步 / 上传 / 拉取合并 / 历史快照回滚）、备份（导出 / 导入，文件或粘贴）、**历史笔记导入**、高级排查区

### ② 只有开发者本人可用（`OWNER_ONLY`）

对外发布时**一律关闭**，入口按身份隐藏、页面自身拦截、云函数拒绝非本人（三层）：

| 功能 | 为什么关 |
| --- | --- |
| **AI 教练**（`pages/coach`） | 属"生成式人工智能服务"，公开要合规 |
| **AI 周训练建议**（`pages/aiplan`） | 同上；只把汇总数字发给 DeepSeek，**从不发笔记原文**，按周缓存 |
| **AI 识别导入**（`pages/importhist` 里的"让 AI 试"） | 同上；会把笔记原文发给第三方，必须明确告知 |
| **同门小队**（`pages/team`） | 会把训练汇总展示给他人（"向第三方提供"），隐私指引要单独声明 |

开关在 `utils/const.js` 的 `OWNER_ONLY = { ai: true, team: true }`，闸门在 `utils/gate.js`。想开放某一项，改一行常量即可，页面代码不用动。

### ③ 未打包 / 已下线

- **姿态自查**（`pages/pose`）：页面代码保留，但**已从 `app.json` 的 pages 里移除** —— 不打包、不调用相机与相册，所以隐私指引里也不需要声明摄像头/相册读取。端上识别在用户机型上没跑通（详见「已知局限」）。

## 你需要在微信侧完成的步骤（只有你能做）

1. **注册小程序账号**：mp.weixin.qq.com → 个人主体（免费）。个人主体类目受限，工具类一般可发布。
2. **ICP 备案**：2023 年起小程序强制备案，**这一步最耗时**（工信部审批）。已完成后才能提审。
3. **导入项目**：微信开发者工具 → 导入本目录 → 填你的 AppID（或 `project.config.json` 的 `appid`）。
4. **开通云开发**：工具栏「云开发」→ 创建环境 → 环境 ID 填到 `app.js` 的 `ENV`。
5. **建 4 个集合**（云开发控制台 → 数据库；权限默认「仅创建者可读写」即可，小程序端**不直连数据库**）：
   - `planner_data`：当前数据（按 openid 隔离，分块存储）
   - `planner_history`：云端历史快照（保留 5 份，可回滚）
   - `planner_team` / `planner_team_stat`：同门小队（首次调用自动创建）
6. **部署云函数**（每个都要选「上传并部署：**云端安装依赖**」）：
   - `login`（判断是不是开发者本人）、`deepseek`（AI，需配 `DEEPSEEK_KEY`，超时调到 60 秒以上）、`remind`（考级提醒，需配 `EXAM_TMPL_ID`）、`friend`（同门）
   - ⚠️ 报 `请在编辑器云函数根目录（cloudfunctionRoot）选择一个云环境` → 右键 `cloudfunctions` 目录选环境。完整步骤见 [`云函数部署清单.md`](../云函数部署清单.md)
7. **填隐私保护指引**（后台 → 设置 → 服务内容声明）：只需声明「**相册（仅写入）**」和「**选中的文件**」两项。可照抄 [`隐私保护指引.md`](../隐私保护指引.md)
8. **填名称 / 头像 / 简介 / 服务类目** → **提交审核** → 通过后点**发布**。类目走「体育运动 / 运动健身」，简介与提审文案见 [`正式发布清单.md`](../正式发布清单.md)
9. **真机验证**：模拟器与手机 openid 不同，**同步、相册、分享图都必须在真机验证**。
10. **微信认证（可选，300 元/年量级）**：未认证时**不能被搜索、不能被分享**，但**不影响发布**。想开放同门（靠分享卡片邀请）时必须认证。

## 数据导入 / 导出

### 备份 JSON（换手机、误删恢复）

- 导出：设置 → 数据备份 →「💾 导出备份」（文件或粘贴）
- 导入：设置 →「📥 导入备份」→ 从文件选择 / 粘贴 JSON 文本
- **按 id 合并，只补不删**；导入前自动备份本机记录，可在高级区「↩︎ 恢复导入前」回退

### 历史笔记（微信收藏 / 备忘录里几年的流水账）

设置 → 「📝 把旧笔记搬进来」，三条路：

1. **粘原始笔记** → 「按日期识别」：认得 `2024-03-15` / `2024.3.15` / `3月15日` / `3/15`；没写年份的沿用上一条年份，拼出来在未来的回退一年；非法日期不误切
2. **复制提示词 → 用你自己的 AI 转格式**（豆包 / ChatGPT / DeepSeek 都行）→ 把返回的 JSON 粘回来。**推荐这条路**：不花本项目的钱、不经过我们的服务、可以反复追问纠错
3. （仅开发者）「🤖 让 AI 试」→ 走 `deepseek` 云函数，提示词写死三条硬规矩：**不许编日期 / 不许输出时长 / 不许润色**

**统计口径**（这一条是设计重点）：导入的每条可选
- **计入上冰统计**（默认）：天数、次数会算进去；正文里写了「90 分钟 / 1.5 小时 / 2 节」会照抄成时长（1 节 = 30 分钟），没写就是 0
- **只当笔记**：`noteOnly = true`，不进任何统计，只在搜索和日历当天出现

去重靠"日期 + 内容"哈希当 id，**同一段粘两次不会灌两遍**。

## 数据安全：发版不丢数据，不靠自觉

- **版本化迁移 + 自检**：`APP_VERSION` 每次发版 +1；启动发现版本变了 → ①整份数据存本机快照 → ②跑迁移 → ③自检（记录条数不能变少、用户写下的每一行字都要还能找到）。不通过会在首页提示、设置里标红，可「恢复升级前数据」一键回退（只补不删）
- **云同步防覆盖**：上传前比较条数与内容，本机明显更少时**跳过自动上传并询问**；**开发者工具不参与自动同步**（保护真实数据）；拉取只补不删；云端保留 5 份快照
- **统计口径唯一入口**：`store.countedRecords()` / `isCounted()` —— 导入的历史笔记不会污染天数、时长、趋势、冰感、冰鞋小时数、AI 的事实摘要
- **修过的三条真会丢字的路径**：①网页版导出的 `notes` 在小程序里看不见且会被清空 → 改成可重复迁移；②考纲改内置时直接删旧外壳会连带删掉用户要点 → 先搬家再丢壳；③"本机最后改动时间"只存内存，重启后未推送的改动会被云端旧版盖掉 → 改为落盘
- **删除可撤销**：删除后首页出现「已删除 · 撤销」横条（12 秒，内存保留 60 秒，按原位置插回）

## 已知局限 / 主动放弃的东西

- **语音录入：已放弃（不是待办）**。微信「同声传译」插件个人主体用不了；云函数侧的"语音转写 → 结构化笔记"提示词仍在，接入第三方 ASR 需评估成本与隐私
- **姿态自查：端上识别没跑通，页面已不打包**。用户机型上 VisionKit `createVKSession` 能创建，但 `detectBody` 返回 **0 个关键点**。已实测的边界（macOS 侧 `tools/pose/` 在同一段 720p/30fps 侧面视频上的结论）：检出率 96.2%、主要关节置信度 0.64–0.76；**浮足高度 / 膝角 / 上身前倾 / 单足时长可做**，**用刃（内/外刃）、跳跃高度、旋转圈数不可做** —— 用刃要判 3–4.7mm 厚度相对冰面的倾斜方向，关键点模型到脚踝为止，3m/1080p 下接触点偏移只有 2–3 像素，叠加冰面过曝与运动模糊，只能给出"看似合理但错误"的反馈
- **考级大纲逐级内置**：目前只录入部分级别（以官方大纲书为准，带页码）；自由滑其它级别待录入
- **AI 知识库**：约 1237 个知识块 / 108 万字符（`cloudfunctions/deepseek/kb_data.js`），带 `discipline`/`doc`/`season`/`lang`/`page`/`section` 元数据；检索有中→英术语映射、覆盖率打分、项目过滤、**赛季隔离**（默认只用当季 + 长期有效条款）。⚠️ **生成物不入库**（含官方文件全文，受版权保护），需用 `滑冰官方资料/生成云函数知识库.py` 在本地生成后部署
- **互转字段丢失**：小程序 → 网页版时，网页版不认识 `units`（节数）/`lessonForm`/`examPicks`/`itemOrder`，**以小程序的导出为准**
- **主包上限 2MB**：新增图片先压缩（≤150KB、宽度 ≤1200px），多了改用分包或云存储（步法图就放在 `packageExam/images/`）
- **同门小队：单机性质**。同一个小程序在模拟器和手机上 openid 相同，只能自己跟自己；真正验证要两个微信号
