# 花样滑冰训练规划（微信小程序版）

把现有网页版(PWA)「花样滑冰训练规划」移植成微信小程序，并在此基础上扩展了动作库、考级备考、里程碑、AI 教练等功能。**目前 8 个主页面 + 1 个分包均已跑通并在日常使用**，功能持续迭代中。

> PWA 网页版仍可正常使用；两者数据可通过「导出/导入 JSON」互转迁移。

## 你需要在微信侧完成的步骤（只有你能做）

1. **注册小程序账号**：https://mp.weixin.qq.com → 立即注册 → 小程序 → 个人主体（免费，无需认证，但类目受限；工具类一般可发布）。
2. **导入项目**：下载「微信开发者工具」→ 导入本目录 `01-skating-coach/miniprogram/` → 用你的小程序 AppID 登录（或在 `project.config.json` 的 `appid` 填）。开发者工具有「测试号」可先本地跑通。
3. **开通云开发**：开发者工具工具栏「云开发」→ 创建环境 → 把环境 ID 填到 `app.js` 的 `ENV`。
4. **建两个数据库集合**（云开发控制台 → 数据库 → 新建集合，权限都选「仅创建者可读写」）：
   - `planner_data`：当前数据（单文档，按 openid 隔离）
   - `planner_history`：**云端历史快照**（每次上传前自动存旧版，保留 5 份，可回滚）
5. **部署云函数**：在开发者工具资源管理器里，分别右键 `cloudfunctions/login` 和 `cloudfunctions/deepseek` → 「上传并部署：云端安装依赖」。
   - 然后给 `deepseek` 云函数**配置环境变量 `DEEPSEEK_KEY`**（值 = 你的 DeepSeek API Key），路径：云开发控制台 → 云函数 → deepseek → 配置 → 环境变量。这样 Key 只存在云端，不进小程序包。
   - 注意把云函数**超时时间调到 60 秒以上**（大模型响应较慢）。
6. **真机预览**：点「预览」用微信扫码在手机运行，或「真机调试」。**模拟器和手机是不同 openid，模拟器的数据不会出现在手机上**，同步相关功能请在真机验证。
7. **发布上线**：小程序后台填名称/头像/简介/服务类目（如「工具 › 效率」），提交代码审核，审核通过后发布；**以后每次更新都要重新提审**。
   - 因涉及把训练数据同步到云，需在后台配置「用户隐私保护指引」（声明收集你的训练记录），代码里已用「用户身份(openid)」隔离数据，符合最小化收集。

## 数据迁移（网页 → 小程序 / 反向）

- **网页 → 小程序**：在网页版 PWA「目标与数据 → 导出备份」点导出（会复制一段 JSON）→ 打开小程序「设置 → 数据备份 → 粘贴导入」→ 导入（按 id 合并，重复跳过）。
- **小程序 → 网页**：小程序「设置 → 数据备份 → 导出为文件 / 复制 JSON」→ 网页版「导入 JSON」粘贴。
- 两边都连通云端后，手工点「上传 / 拉取合并」可互相合并。

### 从纯文本笔记批量导入（六年记录怎么进来的）

如果历史记录是文本（例如"2020.7.3 上课"这样的流水账 + 按日期分块的课堂笔记），可以先用脚本整理成小程序能导入的 JSON：

1. 生成形如 `{ "exportedAt": "...", "records": [ { "id", "date", "type", "mode", "units", "duration", "content", ... } ] }` 的 JSON；
2. 手机「设置 → 数据备份/迁移 → **📂 导入文件**」选微信里的这个 `.json`（或「📥 粘贴导入」）；
3. 导入**按 id 合并**，不会覆盖已有记录；导入前会自动备份本机记录（可在高级区「↩︎ 恢复导入前」回退）。

要点与经验：
- **id 用稳定值**（如 `imp-2020-07-01`），这样重复导入不会产生副本；
- 每条记录**保留原文**（放进 `content`），即使结构化字段有偏差，信息也不丢；
- 剔除非训练内容（例如芭蕾、软开这类不属于滑冰的记录）；
- 用原始记录里的**累计编号当锚点**校验：导入后"累计节数"应当与纸笔记录的编号完全一致。

## 已实现并跑通

- ✅ 首页：月历（周一开头、今天高亮、可翻月）+ 当日训练记录 + 快捷入口 + **固定底部「＋ 添加训练」**。
- ✅ 添加 / 编辑 / 删除训练（`pages/record`）：
  - 类型（上冰 / 陆地）、训练方式（自己 / 上课，冰上才可切换）、日期；
  - **上课按"节数"**（1/2/3/4 节），时长自动 = 节数 × 30 分钟；**自己训练**按 60/90/120/150 分钟选择；
  - **训练笔记**：勾选动作/组合/考级会自动写入条目，手写文字不被覆盖；下方「已选」可**按住 ≡ 拖动排序**；
  - **动作搜索**（同时匹配动作名与组合名）+ 「**最近用过**」（最近 60 天练过的动作，按最近时间排序）。
- ✅ **动作库与动作详情**（`pages/moves`、`pages/move`）：动作级「共性要点」+ 练习组合（各自要点、**新增日期可编辑**、拖动排序、列表显示新增日期）。
- ✅ **考级备考**（分包 `packageExam`，按需预加载，不拖慢主包）：
  - 考级列表按**自由滑 / 步法**分类、按级别（如"步法 · 四级"）；
  - 详情页：**内置考纲只读**（`utils/const.js` 的 `SYLLABUS`，含官方"易犯错误"）+ **内置步法图** + **★我的要点 / 我的易犯错误 / 我的备注** + 自建分节与条目 + 批量粘贴；
  - 设置考级日期后显示**倒计时**，可**一键记入纪念日**；分节**可折叠**（步法图案与我的要点默认展开）。
- ✅ **里程碑 / 纪念日**（`pages/milestone`）：手动记录（上冰纪念、考级、比赛、第一次、康复、自定义），可删除。
- ✅ **训练回顾页**（`pages/review`）：月度统计（次数 / 总时长 / 类型分布 / 上冰课与自练）+ **近 12 个月趋势柱状图** + **本月类型占比** + 累计上冰、累计上冰课次数、**累计节数**（截至所选月份）。
- ✅ **AI 教练对话页**（`pages/coach`）：接 DeepSeek 云函数。
- ✅ **设置与数据管理**（`pages/settings`）：每周上冰目标、次数基线、云同步（自动同步开关 / 上传 / 拉取合并）、备份（导出为文件 / 导入文件 / 粘贴导入）、**「高级 / 数据排查」折叠区**（同步诊断、数据概览、多出的记录、恢复导入前、复制考级原始数据、合并重复记录）。
- ✅ 云同步：按 `openid` 隔离，存到微信云开发数据库（单文档，1MB 内），手机微信 ↔ 电脑微信桌面版共用一份。
- ✅ **自动同步（默认开启）**：启动后自动拉取，改动几秒后自动上传。带多重防覆盖保护——上传前比较本机与云端记录条数，本机明显更少时**跳过自动上传并询问用户**；**开发者工具不参与自动同步**；**导入/拉取前自动备份**；考级数据**深合并**、`meta`（基线）**取大值合并**；云端保留最近 5 份快照可回滚。见 `utils/sync.js`。
- ✅ **课堂笔记整理（AI 侧）**：云函数 `deepseek` 支持 `note` 模式，把口语化的语音转写（含错字、重复、漏词、无标点）整理成按固定分节输出的 Markdown 课堂笔记。**注意：小程序端的语音录制入口目前没有做**（见下）。

## 持续迭代中 / 已知局限

- **语音录入：已放弃（不是待办）**。原计划用微信官方「微信同声传译」插件做录音 + 中文识别，但**个人主体小程序无法使用该插件**，这条路线走不通；云函数侧的"语音转写 → 结构化笔记"提示词仍在，若有第三方 ASR 可再接入（需评估成本与隐私）。
- **AI 知识库的来源需要加固**：目前 5 份 ISU 资料是**中文翻译**、**没有原文链接**、**赛季不统一**（2024-25 / 2025-26 / 2026-27 混用）。计划给每条知识块加**来源元数据**（文号、赛季、页码、是否核对），过季内容隔离，并在回答时声明"中译非原文"；同时补 ISU 官方英文原文对照。
- **考级大纲逐级内置**：目前内置「步法 · 四级」（含步法图）；自由滑 1–10 级与其它步法级别待录入（以官方大纲书为准，带页码）。
- **AI 读取个人数据**：现在只能手动「复制我的易错」再粘给 AI；计划让云函数按 openid 读取考级笔记与动作库要点，作为回答上下文。
- AI 教练回答的持续调优与知识库内容补充。

## 注意事项

- 数据只存云端开发数据库 + 本机缓存；请勿把 `app.js` 之外的安全信息（如 Key）放进前端代码。DeepSeek Key 只存在云函数环境变量。
- 个人主体小程序不能涉及支付、医疗等类目；发布前注意微信内容规范。
- **主包上限 2MB**：新增图片请先压缩（建议 ≤150KB、宽度 ≤1200px），图片多时改用**分包**或云存储。本项目的步法图就是压缩到 155KB 后放进子包的（`packageExam/images/`）。
