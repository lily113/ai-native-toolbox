# 花样滑冰训练规划（微信小程序版）

把现有网页版(PWA)「花样滑冰训练规划」移植成微信小程序，并在此基础上扩展了动作库、里程碑、AI 教练等功能。**目前 8 个主页面 + 1 个分包均已跑通并在日常使用**，功能持续迭代中。

> PWA 网页版仍可正常使用；两者数据可通过「导出/导入 JSON」互转迁移。

## 你需要在微信侧完成的步骤（只有你能做）

1. **注册小程序账号**：https://mp.weixin.qq.com → 立即注册 → 小程序 → 个人主体（免费，无需认证，但类目受限；工具类一般可发布）。
2. **导入项目**：下载「微信开发者工具」→ 导入本目录 `01-skating-coach/miniprogram/` → 用你的小程序 AppID 登录（或在 `project.config.json` 的 `appid` 填）。开发者工具有「测试号」可先本地跑通。
3. **开通云开发**：开发者工具工具栏「云开发」→ 创建环境 → 把环境 ID 填到 `app.js` 的 `ENV`（或先留默认用当前环境）。
4. **部署云函数**：在开发者工具资源管理器里，分别右键 `cloudfunctions/login` 和 `cloudfunctions/deepseek` → 「上传并部署：云端安装依赖」。
   - 然后给 `deepseek` 云函数**配置环境变量 `DEEPSEEK_KEY`**（值 = 你的 DeepSeek API Key），路径：云开发控制台 → 云函数 → deepseek → 配置 → 环境变量。这样 Key 只存在云端，不进小程序包。
5. **真机预览**：点「预览」用微信扫码在手机运行，或「真机调试」。
6. **发布上线**：小程序后台填名称/头像/简介/服务类目（如「工具 › 效率」），提交代码审核，审核通过后发布；**以后每次更新都要重新提审**。
   - 因涉及把训练数据同步到云，需在后台配置「用户隐私保护指引」（声明收集你的训练记录），代码里已用「用户身份(openid)」隔离数据，符合最小化收集。

## 数据迁移（网页 → 小程序 / 反向）

- **网页 → 小程序**：在网页版 PWA「目标与数据 → 导出备份」点导出（会复制一段 JSON）→ 打开小程序「目标与数据 → 导入 JSON」粘贴 → 导入（按 id 合并，重复跳过）。
- **小程序 → 网页**：小程序「导出备份」复制 JSON → 网页版「导入 JSON」粘贴。
- 两边都同时连通云端后，手工点「上传/拉取」可互相合并。

## 已实现并跑通

- ✅ 首页：月历（周一开头、今天高亮、可翻月）+ 选中日当天的训练记录列表。
- ✅ 添加 / 编辑 / 删除训练：类型（上冰/陆地/康复）、训练方式（自己/上课，冰上才可切换）、日期、时长、内容、课后总结（上课时）、备注。
- ✅ **动作库与动作详情**（跳 / 转 / 步），见 `pages/moves`、`pages/move`。
- ✅ **里程碑时间线**（自动触发第 N 次上冰等），见 `pages/milestone`。
- ✅ **训练回顾页**，见 `pages/review`。
- ✅ **AI 教练对话页**，见 `pages/coach`。
- ✅ **动作等级考试**（分包 `packageExam`，按需预加载，不拖慢主包）。
- ✅ 设置与数据管理：备份导出 / 导入（JSON，合并去重）、云同步开关，见 `pages/settings`。
- ✅ 每周上冰目标（分钟）。
- ✅ 云同步：按你的微信身份(openid)隔离，存到微信云开发数据库（单文档，1MB 内），手机微信 ↔ 电脑微信桌面版共用一份。
- ✅ DeepSeek 云函数（`cloudfunctions/deepseek`）：带本地知识库检索（含转体术语参考：内勾/外勾/转3/括弧/捻转等），遵循官方优先 + 诚实原则；调用走云端，避开小程序外域白名单与 CORS。**完整官方资料/个人笔记**见 `kb.js` 内说明，把旧网页版 `AI_OFFICIAL`、`AI_KNOWLEDGE` 文本粘进去即可。

## 注意事项

- 数据只存云端开发数据库 + 本机缓存；请勿把 `app.js` 之外的安全信息（如 Key）放进前端代码。DeepSeek Key 只存在云函数环境变量。
- 个人主体小程序不能涉及支付、医疗等类目；发布前注意微信内容规范。
