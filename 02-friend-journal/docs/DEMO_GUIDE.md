# 演示指南

本文档提供了朋友型电子手账应用的演示流程和说明。

## 项目概述

**项目名称**：朋友型电子手账（Friend Journal）

**核心价值**：
- AI陪伴与情绪疗愈
- 低门槛记录生活与情绪
- 自动生成精美手账
- 提供仪式感与成就感

## 技术栈

- **前端**：React + TypeScript + Tailwind CSS + Fabric.js
- **后端**：Node.js + Express + TypeScript
- **数据库**：PostgreSQL
- **AI服务**：OpenAI GPT-4

## 演示流程

### 1. 启动项目

```bash
# 安装依赖
npm run install:all

# 配置环境变量
# 后端：backend/.env
# OPENAI_API_KEY=your_key
# DATABASE_URL=postgresql://...

# 启动数据库（需要先创建数据库）
# psql -U postgres
# CREATE DATABASE friend_journal;
# \i backend/src/db/schema.sql

# 启动开发服务器
npm run dev
```

### 2. 核心功能演示

#### 2.1 AI聊天功能

1. 进入聊天页面 (`/chat`)
2. 与AI朋友聊天，可以选择不同的人格（温柔/幽默/理性）
3. 观察AI的回复是否符合设定的人格特点
4. 查看聊天历史记录

**演示要点**：
- AI能够理解用户情绪并给予适当回应
- 不同人格的回复风格有明显差异
- 对话流畅自然

#### 2.2 手账生成功能

1. 在聊天页面进行一段对话
2. 进入手账页面 (`/journal`)
3. 点击"生成新手账"按钮
4. 观察AI自动提取内容并生成手账
5. 查看生成的手账预览
6. 测试导出功能（PNG/PDF）

**演示要点**：
- AI能够从聊天记录中提取关键信息
- 生成的手账排版美观、内容完整
- 支持导出为图片或PDF

#### 2.3 分享功能

1. 在某个手账的预览页面
2. 点击"分享"按钮
3. 选择要隐藏的内容（情绪、事件、个人信息）
4. 生成分享版手账
5. 导出分享版手账

**演示要点**：
- 能够过滤敏感信息
- 生成适合分享的版本

#### 2.4 总结功能

1. 确保有多篇手账（至少3-5篇）
2. 进入总结页面 (`/summary`)
3. 选择总结类型（周/月/年）
4. 点击"生成总结"
5. 查看情绪变化曲线
6. 查看高光事件列表

**演示要点**：
- AI能够分析情绪变化趋势
- 自动提取高光事件
- 可视化图表展示清晰

### 3. AI价值创造点演示

1. **智能对话**：展示AI如何理解用户情绪并给予个性化回应
2. **内容提取**：展示AI如何从聊天记录中提取关键信息
3. **排版设计**：展示AI如何根据内容生成合适的排版方案
4. **情绪分析**：展示AI如何分析用户情绪变化

## 问题与解决方案

### 问题识别
- **问题1**：现代人缺乏倾诉渠道，情绪难以释放
- **问题2**：手账制作门槛高，需要时间和审美能力
- **问题3**：记录生活缺乏仪式感和成就感

### 解决方案
- **AI陪伴**：提供24小时可用的AI朋友，降低倾诉门槛
- **自动生成**：AI自动提取内容和设计排版，降低制作成本
- **仪式感**：每日固定生成手账，提供回顾和总结功能

### 价值主张
- 心理陪伴与情绪疗愈
- 精美记录无需专业技能
- 仪式感与成就感

## 技术亮点

1. **AI提示词工程**：精心设计的提示词实现不同功能
2. **Canvas渲染**：使用Fabric.js实现高质量手账渲染
3. **数据可视化**：使用Chart.js展示情绪变化
4. **前后端分离**：清晰的架构设计

## 注意事项

1. **API密钥**：确保配置正确的OpenAI API密钥
2. **数据库**：确保PostgreSQL数据库正常运行
3. **网络**：需要稳定的网络连接访问OpenAI API
4. **成本**：注意OpenAI API的调用成本
